# daatools/man/reset_gfx.Rd

```
\name{reset_gfx}
\alias{reset_gfx}
\title{Zurücksetzen bei Grafik-Fehlern}
\description{
  Setzt ausgewählte Grafikparameter des aktuellen Grafikgeräts zurück:
  eine Grafik pro Zeichenfläche, Ränder von \code{c(4, 2, 2, 2)} Textzeilen
  und Beschränkung der Zeichnung auf den Plotbereich (\code{xpd=FALSE}).
}
\usage{
  reset_gfx()
}
```
